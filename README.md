# Rick and Morty Character Directory (gbu-project)

Интерактивный каталог персонажей из вселенной «Рик и Морти». В проекте присутствует динамический поиск, фильтрация, пагинация,главная страница каталога и страница с детальной информацией о персонаже.

---

## Реализованные возможности

* **Каталог персонажей:** Адаптивная сетка карточек с цветовой индикацией статуса персонажа (*Alive*, *Dead*, *Unknown*).
* **Поиск и фильтрация:**
  * Поиск персонажей по имени.
  * Фильтрация по жизненному статусу.
* **Пагинация:** Постраничный просмотр каталога с отображением текущей страницы и кнопками навигации.
* **Страница деталей:**
  * Подробная информация о персонаже.
  * История эпизодов, в которых персонаж появлялся.
  * Переход обратно в каталог.

---

## Стек технологий

* **Frontend:** React
* **Styling:** CSS
* **API:** [The Rick and Morty API](https://rickandmortyapi.com/)

---

## Структура компонентов

### 1. Card
Компонент карточки персонажа в общем списке.
* **Props:** `name`, `status`, `image`, `id`.

### 2. CardsList
Основной компонент списка персонажей.
* Отвечает за запрос к API с учётом текущей страницы, поискового запроса и фильтра статуса.
* Управляет состояниями загрузки (`loading`), ошибок (`error`).

### 3. SearchInput
Блок фильтрации и поиска персонажей.
* Включает текстовый инпут поиска и выпадающий список статусов.

### 4. Pagination
Панель навигации по страницам API.
* Кнопки «Вперёд/Назад» и информер текущей страницы.

### 5. CharacterDetail
Страница детальной информации о выбранном персонаже.
* Загружает расширенные данные и список эпизодов с указанием даты выхода.
